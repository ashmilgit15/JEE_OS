## Project Overview

**JEE OS** — A Next.js 16.4.6 + React 19.2.4 application for JEE (Joint Entrance Examination) preparation. Features include AI tutor/coach, syllabus tracking, question bank, analytics, revisions planner, flashcards, mock tests, and study logging.

**Stack:** Next.js App Router, Tailwind v4 (CSS-first), `@base-ui/react` (NOT Radix), Supabase SSR, Hack Club AI Proxy, Tavily search.

**Important:** This Next.js version has breaking changes from older versions — APIs, conventions, and file structure may differ from training data. Read the relevant guide in `node_modules/next/dist/docs/` before writing Next.js-specific code. Heed deprecation notices.

## Architecture

### Routing & Structure
- **Single-page App Router** — all routes flat under `src/app/` (no route groups, no monorepo). Pages: tutor, coach, syllabus, analytics, log, revisions, planner, flashcards, formulas, mocks, tests, replay, peers, resources, settings, profile, advanced.

### State Management
- **Custom React Context + `useReducer`** entirely in `src/store/index.tsx` (~2300 lines; the `Action` union type is defined inline there — there is no separate actions file)
- Persisted to `localStorage` under key `jee-os-state`; also synced to Supabase via `src/utils/supabase/sync.ts` on mount

### UI Components
- **`@base-ui/react`** (NOT Radix/shadcn) — generated by `shadcn` CLI using the `base-nova` style
- All reusable components in `src/components/ui/`; layout-level components (Sidebar, FloatingAICopilot, QuickLoggerDrawer) in `src/components/layout/`
- Components use the `render` prop for polymorphic composition (NOT `asChild`)

### Authentication & Sync
- **Supabase SSR** via `@supabase/ssr`. Clients: `src/utils/supabase/client.ts` (browser), `server.ts` (server — requires `cookieStore` from `next/headers`), `middleware.ts` (session refresh in proxy)
- `src/utils/supabase/sync.ts` — signs in **anonymously** if no session, caches a device ID in `localStorage` (`jee-os-device-id`), seeds topics, and syncs logs/revisions/tests/mistakes
- `src/utils/supabase/conversations.ts` — persists AI chat conversations
- `revision_tasks` table must exist — run `supabase_schema.sql` in the Supabase SQL editor. `sync.ts` checks once per session and degrades with a `console.warn` if missing.

### Middleware
- `src/proxy.ts` (Next.js 16 renamed `middleware.ts` → `proxy.ts`) — delegates to `utils/supabase/middleware.ts` `createClient`, which refreshes the session via `supabase.auth.getUser()` and returns the response

### Styling
- **Tailwind v4 CSS-first** — `@theme` in `src/app/globals.css`; there is NO `tailwind.config.js`, do not create one
- Dark-first design only; CSS variables use `oklch()` (not hex/rgb)
- Button defines custom CVA sizes: `xs`, `icon-xs`, `icon-sm`, `icon-lg`

### API
- `/api/chat/route.ts` (~2000 lines) — streams NDJSON events for AI tutor/coach; handles tool-like intents (web search, mock test generation, textbook PDF search)
- Falls back to hardcoded smart responses if `HACKCLUB_API_KEY` is missing; search features degrade gracefully without `TAVILY_API_KEY`

## Component API Differences from Standard shadcn/Radix

- `@base-ui/react` uses `render` prop (not `asChild`) — see `Sidebar.tsx`, `sheet.tsx`
- Tooltip: `TooltipPrimitive.Popup` + `TooltipPrimitive.Positioner` (not Radix's `Content`/`Trigger`)
- Sheet is based on `@base-ui/react/dialog` (not `@radix-ui/react-dialog`)

## Pitfalls (Do Not "Fix" or Re-introduce)

- `api/chat/route.ts` — `topicNameCandidate` uses `let` correctly (reassigned in branches); do not change to `const`
- `tutor/page.tsx` & `FloatingAICopilot.tsx` — `new URL(result.url).hostname` is wrapped in try/catch; preserve this when editing URL handling
- `handoff.md` documents `NEXT_PUBLIC_SUPABASE_ANON_KEY` but the code uses `PUBLISHABLE_KEY` — handoff doc is outdated
- Tailwind v4: `h-4.5` / `w-4.5` are not valid spacing-scale classes

## Environment Variables

Required in `.env.local`:
```
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=...   # NOT ANON_KEY
HACKCLUB_API_KEY=...                       # optional — enables AI features
HACKCLUB_MODEL=...                         # optional — defaults to google/gemini-3.5-flash
TAVILY_API_KEY=...                         # optional — enables web search
```
